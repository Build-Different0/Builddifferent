# LEDGER

**Builddifferent · Day 8**

> Compliance that never sleeps.

LEDGER is a live assurance operating system for GRC managers.

It is intentionally not a dashboard or cinematic landing page. It opens directly into operational work.

## Product views

### Today
A live assurance ledger showing evidence collection, configuration changes, vendor updates, expiring reviews, and AI observations.

### Controls
Living control twins with expected versus actual state, evidence reliability, framework mappings, exceptions, ownership, and OSCAL export.

### Replay
A historical assurance engine that lets GRC teams scrub through the year and see how control confidence changed.

### Auditor
A controlled portal where auditors ask questions directly against evidence lineage, test history, populations, and exceptions.

## Features

* Live operational assurance feed
* Inline event expansion
* Evidence strength, freshness, coverage, and tamper resistance
* Expected state versus actual state
* Evidence lineage
* Contextual evidence requests
* Population-aware testing
* Vendor assurance
* Exceptions and compensating-control workflow
* Framework mappings
* OSCAL export concept
* AI evidence challenges
* Automation recommendations
* Control twins
* Assurance replay
* Auditor Q&A
* Command palette with keyboard shortcut
* Responsive application layout

## Run

Open `index.html` with VS Code Live Server.

No dependencies or build process are required.
