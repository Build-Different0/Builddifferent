# SHADOW

**Builddifferent · Day 7**

> Every app has a first attacker. Meet yours.

SHADOW is a cinematic pre publish adversarial AI experience. It preserves the Application Security Engineer brief: create accounts with different permissions, manipulate requests, test authorization boundaries, attempt safe data extraction, inspect exposed secrets, simulate malicious behavior, generate a reproducible attack demonstration, and propose a safe repair.

## Experience

1. Publish countdown
2. Unknown attacker enters
3. Autonomous reasoning and attack
4. Visible interface damage
5. Deterministic request and response replay
6. Minimal safe repair
7. Same exploit reruns
8. Patched app blocks it

Open `index.html` using VS Code Live Server. No installation is required.

This is a fictional defensive simulation. It contains no operational exploit code, credentials, malware, destructive payloads, or instructions for unauthorized access.


## Premium security theme

The experience and interaction model remain unchanged.

The visual system now uses:

* Neutral graphite as the dominant environment
* Warm bone for high contrast primary content
* Layered surfaces that become lighter with elevation
* Signal red only for active compromise and danger
* Muted cyan for system intelligence
* Verification green only for successful defense
* Amber for warning and progression
* Reduced gradients and restrained glow
* Stronger contrast, depth, and scene separation
* More refined motion and focus states

The palette follows neutral first, layered surface, and purposeful accent principles used by mature product design systems.
