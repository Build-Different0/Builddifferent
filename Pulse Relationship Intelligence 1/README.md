# Pulse


I built Pulse because important relationships should not quietly go cold just because life gets busy.

This is not another CRM. Pulse is relationship intelligence. It shows me who needs attention, where trust is growing, and what move I should make next.

## What is inside

Founder command center

Relationship health and momentum

Smart signals for investors, customers, candidates, employees, and partners

Pulse Copilot that answers questions about the network

Interaction memory

Add people and log conversations

Premium animations and micro interactions

Browser storage, so the demo keeps working

## Run it

Open this folder in VS Code

Open `index.html`

Click **Go Live**

That is literally it. No install. No API key. No stress.

## The idea

A CRM remembers names.

Pulse remembers what matters.

Built with big founder energy
